| File | Description |

## Overview

The flowcharts describe:
1. Shell initialization
2. Interactive vs non-interactive mode
3. Input parsing and tokenization
4. Built-in command detection
5. PATH resolution
6. Fork/execve/waitpid cycle
7. Exit status handling
